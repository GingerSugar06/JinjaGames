# JinjaGames Logo Promptu (Gemini / görsel model)

**Kurallar:**
- Renkler: **turuncu + beyaz** ana; ek olarak sıcak amber/kömür siyahı olabilir.
- **"J" harfini kullanma / harf logosu olmasın.** Soyut/ikonik bir işaret olsun.
- **Oyunu hissettirsin.** ("Jinja" ninja çağrışımı yapar, ondan yararlanabilirsin.)
- Hem **PC hem mobil** oyunları çağrıştırsın (evrensel, temiz, hem büyük hem küçük ölçekte okunur).
- Düz vektör, **şeffaf arka plan**, ikon olarak da (app icon) çalışsın.

---

## Ana prompt (öneri 1: Shuriken + Play)
```
A modern, minimal logo mark for an indie game studio called JinjaGames. An abstract four-point ninja shuriken (throwing star) whose top point subtly forms a "play" triangle, suggesting gaming and motion. Bold, geometric, playful yet professional. Orange to amber gradient with clean white negative space, on a transparent background. Flat vector, crisp edges, works as a small app icon and as a large logo. No letters, no text, no realistic face.
```

## Alternatif prompt (öneri 2: Spark + Pixel)
```
A minimal geometric logo icon for a game studio named JinjaGames. An abstract spark or star burst built from a few bold angular shards, with one shard shaped like a rounded play button. Energetic and fun, evoking both PC and mobile gaming. Orange and amber on white, subtle depth, flat vector, transparent background, app-icon friendly. No letters, no text.
```

## Alternatif prompt (öneri 3: Yuvarlak rozet)
```
A rounded-square app badge logo for JinjaGames game studio. Inside: an abstract ninja star fused with a pixel/play motif, glowing warm orange on soft white, playful and clean. Minimal flat vector, subtle inner glow, transparent background, reads well at 32px and at large sizes. No letters, no text.
```

---

## İpuçları
- Üç öneriyi de üret, en iyisini seç. Sonra bana ver, siteye + Steam'e + oyuna yerleştirelim.
- Aynı işaretin **tek renk (beyaz)** ve **tek renk (turuncu)** versiyonlarını da iste (koyu/açık zeminler için).
- App icon için **kare, kenarlıksız, ortada işaret** varyantı da iste.
- Favicon + Steam ikonu + mobil app icon aynı işaretten türeyecek.
